# ADR-0009: документацией владеет репозиторий

- Status: accepted
- Date: 2026-08-28

## Решение

Каждая репа хранит README, AGENTS.md, `catalog-info.yaml`, `mkdocs.yml` и каталог `docs`. CODEOWNERS назначает
ревью документации владельцу репозитория. Общие решения хранятся в `platform`, локальные — рядом с сервисом.

## Причина

Человек и будущий AI-агент могут быстро узнать назначение, границы, команды и текущие решения без полного
повторного анализа кода.

## Последствия

Документация меняется вместе с кодом. CI проверяет структуру, ссылки и сборку, но смысл и актуальность текста
проверяет владелец во время ревью.
