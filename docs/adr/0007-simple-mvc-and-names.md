# ADR-0007: обычный MVC и простые английские имена

- Status: accepted
- Date: 2026-08-28

## Решение

В сервисах используется понятный поток `controller → service → repository`. Дополнительный слой добавляется
только при реальной необходимости. Имена классов и методов состоят из простых английских слов.

## Причина

Структура должна быть понятна разработчику с английским уровня A2. Прямые названия ускоряют обучение и ревью.

## Последствия

Предпочитаются имена `ActionController`, `ActionService`, `ActionRepository`, `create`, `find`, `save`.
Сложные шаблоны и термины должны быть обоснованы задачей, а не желанием подготовиться ко всем будущим случаям.
