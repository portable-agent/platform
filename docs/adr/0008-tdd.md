# ADR-0008: TDD для нового поведения

- Status: accepted
- Date: 2026-08-28

## Решение

Новое поведение создаётся коротким циклом: падающий тест, минимальный рабочий код, улучшение структуры.
Уровень теста выбирается по риску: unit, MVC, repository с Testcontainers или contract test.

## Причина

На этапе каркаса тесты фиксируют инженерные границы до появления бизнес-логики и помогают безопасно менять
структуру сервисов.

## Последствия

Pull request с новым поведением обычно содержит тест. Простые файлы конфигурации не требуют искусственного
unit-теста, но должны проходить подходящую автоматическую проверку.
